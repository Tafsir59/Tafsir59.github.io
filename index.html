01

📦 Objects & Classes (OOP)

Understand what objects and classes are — the blueprint and the instance.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🟢 Beginner
Watch on YouTube ↗

🔑 Key Concepts

  • A class is a blueprint/template that defines properties (fields) and behaviors (methods)
  • An object is an instance of a class created using the new keyword
  • Fields store state; methods define behavior
  • Multiple objects can be created from a single class
02

🏗️ Constructors

Special methods that initialize objects when they're created.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🟢 Beginner
Watch on YouTube ↗

🔑 Key Concepts

  • Constructor name must match the class name
  • No return type (not even void)
  • Called automatically when object is created with new
  • Default constructor is provided if none is defined
03

🔭 Variable Scope

Local vs instance vs class-level variables — where they live and how long.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🟢 Beginner
Watch on YouTube ↗

🔑 Key Concepts

  • Local variables — declared inside a method, only available there
  • Instance variables — declared in a class, one per object
  • Class/static variables — shared across all instances
  • Use this to disambiguate instance vs local variables
04

⚙️ Overloaded Constructors

Multiple constructors in one class to support different initialization paths.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🟡 Intermediate
Watch on YouTube ↗

🔑 Key Concepts

  • Same class, multiple constructors with different parameters
  • Java picks the matching constructor at compile time
  • Use this() to call another constructor from within a constructor
  • Enables flexible object creation
05

📝 toString Method

Override toString() to give your objects a human-readable representation.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🟢 Beginner

🔑 Key Concepts

  • toString() is called automatically when you print an object
  • Without override, prints memory address like ClassName@hashcode
  • Override it to print meaningful field values
  • Comes from the base Object class in Java

🗃️ Array of Objects

Store multiple objects in an array and iterate over them efficiently.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🟡 Intermediate

  • Declare with ClassName[] arr = new ClassName[size];
  • Each element is a reference, not a primitive
  • Uninitialized elements are null
  • Use loops to access and modify elements
07

⚡ Static Keyword

Class-level members that belong to the class, not any object instance.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🟡 Intermediate
Watch on YouTube ↗

🔑 Key Concepts

  • Static fields are shared by all instances of a class
  • Static methods can be called without an object: ClassName.method()
  • Cannot use this inside a static method
  • Useful for counters, utility methods, constants
Module 2 — The 4 Pillars of OOP
08

👨‍👩‍👦 Inheritance

Child classes inherit fields and methods from parent classes — reuse without rewriting.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🔵 Core Pillar
Watch on YouTube ↗

🔑 Key Concepts

  • Use extends keyword to inherit from a parent class
  • Java supports single inheritance (one parent class only)
  • Child inherits all non-private members
  • Promotes code reuse and establishes an IS-A relationship
09

🔄 Method Overriding

Redefine a parent method in the child class to specialize behavior.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🔵 Core Pillar
Watch on YouTube ↗

🔑 Key Concepts

  • Same method signature as the parent, in the child class
  • Use @Override annotation to catch mistakes at compile time
  • Return type must be same or a subtype (covariant)
  • Access modifier must be same or less restrictive
10

🦸 super Keyword

Access the parent class's constructor, fields, and methods from the child.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🟡 Intermediate
Watch on YouTube ↗

🔑 Key Concepts

  • super() calls the parent class constructor
  • super.method() calls the parent's overridden method
  • Must be the first statement in child constructor if used
  • Java automatically calls super() if not explicitly written
11

🧩 Abstraction

Hide internal complexity, expose only what's necessary via abstract classes.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🔵 Core Pillar

🔑 Key Concepts

  • Abstract classes cannot be instantiated directly
  • Abstract methods have no body — subclasses must implement them
  • Declared with abstract keyword
  • Can have both abstract and concrete methods

🔑 Key Concepts

  • public — accessible from anywhere
  • private — accessible only within the same class
  • protected — accessible within package + subclasses
  • (default) — accessible within the same package only
13

🛡️ Encapsulation

Bundle data and methods together, and control access through getters & setters.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🔵 Core Pillar

🔑 Key Concepts

  • Setters can validate input before assigning values
  • Protects data integrity and improves maintainability
Module 3 — Advanced OOP
14

📋 Copy Objects

Understand shallow vs deep copy when duplicating object state.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🟡 Intermediate
Watch on YouTube ↗

🔑 Key Concepts

  • Assigning an object variable copies the reference, not the object
  • Shallow copy — copies the reference to nested objects
  • Deep copy — recursively copies all nested objects
  • Copy constructors are a clean Java pattern for object duplication
15

🔌 Interfaces

Define contracts that classes must follow — achieves multiple type inheritance.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🟠 Advanced
Watch on YouTube ↗

🔑 Key Concepts

  • Declared with interface keyword; implemented with implements
  • All methods are implicitly public abstract (before Java 8)
  • A class can implement multiple interfaces
  • Interfaces can have default and static methods (Java 8+)
16

🎭 Polymorphism

One interface, many forms — compile-time (overloading) and runtime (overriding).

▶
▶ Bro Code Video 📗 GeeksForGeeks 🔵 Core Pillar
Watch on YouTube ↗

🔑 Key Concepts

  • Compile-time (static) — method overloading; resolved at compile time
  • Runtime (dynamic) — method overriding; resolved when program runs
  • A parent reference can hold a child object
  • Enables writing flexible, extensible code
17

✨ Dynamic Polymorphism

Runtime dispatch — Java decides which method to call based on the actual object type.

▶
▶ Bro Code Video 📗 GeeksForGeeks 🟠 Advanced
Watch on YouTube ↗

🔑 Key Concepts

  • Also called Dynamic Method Dispatch or late binding
  • A superclass reference variable can reference a subclass object
  • Which overridden method runs is decided at runtime, not compile time
  • Foundation of Java's runtime flexibility and design patterns
